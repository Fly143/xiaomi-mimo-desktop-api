# xiaomi-mimo-desktop-api

English: see [README.md](README.md).

Converts **Xiaomi MiMo Desktop account session** into OpenAI + Anthropic compatible API.
Based on [MiMo2API](https://github.com/Fly143/MiMo2API); upstream is Desktop `/api/route/chat/completions` instead of the web bot.

Models: `mimo-x-pro-preview`, `mimo-x-flash-preview` only. No TTS/ASR.
